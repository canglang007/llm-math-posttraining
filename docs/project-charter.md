# 项目章程

更新时间：2026-11-15 01:15（Asia/Shanghai，UTC+08:00）

## 背景

在线教育/企业场景需要私有化的数学推理解题助手：通用大模型 API 成本高、学生数据不能出域、回答格式和稳定性不可控。一个 4B 小模型经过后训练，可以在成本、隐私和可控性上更合适。

## 目标

用公开 GSM8K/MATH 数据，构建一条可复现的后训练链路：

```text
公开数据
→ 数据引擎（清洗/去重/难度分层/配比）
→ SFT
→ 拒绝采样（答案验证）
→ DPO（正确/错误解答偏好）
→ 公开 test 评测
→ 失败分析
```

主张：数据过滤和拒绝采样能提升 Qwen3-4B-Base 的数学推理 pass@1；并单独量化数据引擎的贡献。

## 非目标

- 不做 Agent、tool calling、user simulator、benchmark 平台；
- 不做预训练、大规模 RL、生产级服务；
- 不用自造标签当主证据；
- 不先上服务器：先完成本地 foundation 和单测。

## 交付物

- 数据准备脚本和 provenance；
- 答案抽取与 pass@1 评测；
- SFT/RFT/DPO 数据构造与训练脚本；
- Base/Public-SFT/RFT/DPO 结果和失败分析；
- 一个可演示的 CLI/Streamlit 解题助手；
- 面试用 1 分钟叙事和 5 分钟 demo。
