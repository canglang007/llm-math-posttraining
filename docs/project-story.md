# 一页纸：LLM Math Post-Training（面试/简历版）

> 更新时间：2026-11-19 20:00（Asia/Shanghai UTC+8）

## 一句话

**在 Qwen3-4B + GSM8K 上，把"后训练数据引擎"做成可量化实验：11 个模型档位、1319 题 test 终评、每步配对显著性检验，并如实报告 8/9 个方法对比不显著。**

## 我做了什么

1. **建数据引擎**：官方 CoT 做 SFT（格式地基）→ 模型自采样 + **答案验证**做 RFT → 用验证器产出的偏好对做 DPO → 在线采样 + 规则奖励做 GRPO。
2. **做可归因的消融**：A2 对照组与 E2b 处理组同起点、同超参、同题量（286 题），**唯一差别是那 37 条（12.9%）错误解是否被过滤**。
3. **换推理引擎前先校准口径**：HF 4bit 与 vLLM bf16 逐题一致率 84.5%，拆解后确认主因是 4bit 量化噪声（同精度两引擎 96.7%），据此把 test 评测迁到 vLLM bf16——1319 题从 15 小时压到 3 分钟/模型。
4. **做失败分析**：把分数拆成「抽取失败率 × 可解析题正确率」，并人工判读分叉题，定位错误机制。

## 结果（test 1319，vLLM bf16 口径）

| 对比 | 数字 | 显著性 |
|---|---|---|
| Base → SFT | 0.7604 → 0.8112，**+5.08pt** | **p=0.0002** |
| RFT 验证 vs 不验证（A2 消融） | 0.8120 vs 0.7945，**+1.74pt** | **p=0.022** |
| 其余 8 个方法 vs SFT | −1.0 ~ +0.91pt | p≥0.23，均不显著 |

## 三个可以讲深的洞察

**① SFT 提升的不是算术，是"会收尾"。** Base 在可解析题上正确率 0.8767（比 SFT 还高），但 13.3% 的题没输出 `####`。SFT 把可解析率从 86.7% 拉到 99.8%，分数随之 +5.08pt。**格式地基价值可量化。**

**② 数据里的错，模型会照学。** 不经验证的采样数据只含 12.9% 错误解，就让 test 掉 1.74pt（p=0.022）；
分叉题的错误形态与训练错解同源（局部算术滑落、推理结构正确）。**验证器不是可选组件。**

**③ 1pt 级效应只有大数据集能判。** 同一个 A2 对比，dev-200 上 p=1.000（判不出），test 1319 上 p=0.022（显著）。
**这解释了为什么很多"方法涨点"的结论不可靠。**

## 技术要点（可被追问的部分）

- **口径工程**：双后端（HF 4bit / vLLM bf16）共存，prompt、停止词、答案截断完全共用；
  `--backend` 切换，`compare_inference_backends.py` 输出判分一致率/答案一致率/翻转明细。
- **统计**：所有对比用 McNemar 配对检验（逐题对齐），报四格与 p 值，不报裸均值差。
- **数据纪律**：test 只评一次、不参与任何选择；自采样数据一律由公开答案验证；`audit_data_integrity.py` 自动巡检泄漏与唯一 id。
- **可复现**：81 个单测（含口径守卫）、配置化训练、所有表格由脚本从预测 jsonl 重算。

## 边界（主动说明，避免被问倒）

- 单模型（4B）× 单数据集（GSM8K），结论不外推到"DPO 无用"；
- 未做多 seed、MATH 跨分布、更大模型——这些是"把结论做宽"，不是"把结论做对"；
- dev 与 test 的结论差异本身是重要发现（见洞察③），不是数据问题。

## 如果面试官问"最有价值的一件事"

不是 0.8203 那个最高分，而是 **A2 消融 + 口径校准这两件事**：
它们把"我训了几个模型"变成"我知道每个数字的可信区间在哪、以及为什么"。

# 简历条目（唯一版本，直接粘贴）

**大模型后训练 · 数学推理数据引擎**｜个人项目｜2026.11｜PyTorch、LoRA、TRL、vLLM

- 以 GSM8K 官方 6973 条思维链微调 Qwen3-4B（LoRA，单卡可复现），再对比拒绝采样微调（RFT）、DPO、GRPO 三类后训练方法与消融设计，统一在 1319 题测试集评测：SFT 使答案可解析率 86.7%→99.8%、准确率 **76.04%→81.12%（+5.08pt，p=0.0002）**，是唯一显著增益，其余方法均不显著（最好 +0.91pt，p=0.23）。
- 设计单变量消融量化答案验证的价值：同批 286 条模型自采样解、同起点同超参，仅控制是否过滤其中 12.9% 的错误解，验证组 **81.20% vs 79.45%（+1.74pt，p=0.022）**，且低于不训练基线 1.67pt——错误数据会被模型当作正确模式习得。
- 将评测链路迁移至 vLLM bf16：1319 题单模型 **5 小时→3 分钟**；迁移前实测新旧口径逐题一致率仅 84.5%，通过三方对照定位为 **4bit 量化噪声（同精度下 96.7%）**，据此建立"双口径不可混表"的评测规范。
